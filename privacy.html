Privacy Policy — Cosmos tools

Last updated: 15 October 2026

"Cosmos tools" is a private application operated by the owner of the Cosmos in Numbers channels and used exclusively by that owner to publish the channel's own videos.

YouTube API Services

Cosmos tools uses YouTube API Services. By using Cosmos tools you agree to be bound by the YouTube Terms of Service. Information accessed through YouTube API Services is also subject to the Google Privacy Policy.

What data we access, use and store

With the owner's explicit OAuth consent (scope youtube.force-ssl), the tool accesses only the owner's own YouTube channel to: upload videos, set titles, descriptions, tags, thumbnails and captions, set publishing schedules, update playlists, set the channel banner and watermark, and list the channel's own videos. It does not access, collect or store data about any other YouTube user or viewer.

The only stored item is the OAuth token, kept on the owner's own computer. No YouTube data is shared with, sold or transferred to any third party, and no cookies or tracking are used by the tool.

Data retention and deletion

The OAuth token is kept only while the tool is in use. The owner can delete all stored data at any time by deleting the token file, and it is deleted within 7 days if access is revoked. Access can be revoked at any time from the Google security settings page: https://myaccount.google.com/permissions. For any deletion request, contact us using the address below.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

TikTok

If used with the owner's TikTok account, the tool only uploads and schedules the owner's own videos. Access can be revoked in the TikTok app (Settings → Security → Manage app permissions).
